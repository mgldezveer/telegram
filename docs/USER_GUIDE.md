# 📚 Руководство пользователя - AI Content Bot

## 🚀 Начало работы

### Запуск бота

1. Найдите бота в Telegram
2. Отправьте команду `/start`
3. Откроется главное меню с кнопками навигации

### Главное меню

После запуска вы увидите главное меню с разделами:

- **📊 Каналы** - управление вашими каналами
- **✍️ Контент** - создание и планирование постов
- **📈 Аналитика** - статистика по каналам
- **⚙️ Настройки** - конфигурация бота

**Быстрые действия:**
- **⚡ Сгенерировать** - создать пост одной кнопкой
- **📊 Статус** - посмотреть состояние системы

---

## 📊 Управление каналами

### Добавление канала

1. Откройте меню **Каналы**
2. Нажмите **➕ Добавить канал**
3. Отправьте ID канала (например: `-1001234567890`)
4. Введите название для канала
5. Готово! Канал зарегистрирован
6. Автоматически откроется меню каналов для дальнейшей работы

**Как найти ID канала:**
1. Перешлите любое сообщение из канала боту @userinfobot
2. Бот покажет ID канала
3. Скопируйте ID и используйте при регистрации

**⚠️ Важно:** Бот должен быть администратором канала с правами на публикацию!

### Просмотр информации о канале

1. Откройте меню **Каналы**
2. Выберите канал из списка
3. Откроется панель управления с информацией:
   - ID канала
   - Статус (активен/приостановлен)
   - Частота публикаций
   - Темы контента

### Действия с каналом

В панели управления доступны:
- **✍️ Создать пост** - сгенерировать контент
- **📅 Расписание** - настроить автопубликацию
- **⚙️ Настроить** - изменить параметры
- **📊 Аналитика** - посмотреть статистику
- **🗑️ Удалить** - удалить канал (с подтверждением)

### Удаление канала

1. Выберите канал
2. Нажмите **🗑️ Удалить**
3. Прочитайте последствия
4. Подтвердите удаление или отмените

**Последствия удаления:**
- Все настройки канала будут удалены
- История постов будет архивирована
- Запланированные публикации будут отменены

## ✍️ Создание контента

### Генерация поста

**Способ 1: Через меню**

1. Откройте меню **Контент**
2. Нажмите **Сгенерировать**
3. Выберите канал
4. Выберите тему:
   - 💻 Технологии
   - 🎨 Дизайн
   - 📱 Мобильные
   - 🚀 Стартапы
   - ✏️ Своя тема...
5. Дождитесь генерации
6. Просмотрите пост

**Способ 2: Быстрая генерация**

1. В главном меню нажмите **⚡ Сгенерировать**
2. Бот автоматически:
   - Выберет первый доступный канал
   - Использует тему по умолчанию
   - Сгенерирует и опубликует пост
3. Получите уведомление об успехе

### Своя тема

1. При выборе темы нажмите **✏️ Своя тема...**
2. Введите тему (3-200 символов)
3. Примеры тем:
   - "Искусственный интеллект в медицине"
   - "Тренды веб-разработки 2024"
   - "Как начать карьеру в IT"
4. Бот сгенерирует пост по вашей теме

### Предпросмотр поста

После генерации вы увидите:
- Текст поста
- Хештеги (если есть)
- Кнопки действий

**Доступные действия:**
- **✅ Опубликовать** - опубликовать пост в канале
- **✏️ Редактировать** - изменить пост (в разработке)
- **🔄 Перегенерировать** - создать новый вариант
- **❌ Отменить** - отменить публикацию

### Публикация поста

1. Просмотрите пост
2. Нажмите **✅ Опубликовать**
3. Дождитесь подтверждения
4. Пост опубликован в канале!

### Регенерация поста

Если пост не понравился:
1. Нажмите **🔄 Перегенерировать**
2. Бот создаст новый вариант с той же темой
3. Просмотрите новый пост
4. Опубликуйте или регенерируйте снова

### Просмотр постов

Для просмотра всех постов:
1. Откройте меню **Контент**
2. Выберите **📝 Просмотр постов**
3. Выберите канал
4. Используйте фильтры для отображения:
   - **Все** - все посты
   - **Черновики** - неопубликованные посты
   - **Запланированные** - посты в расписании
   - **Опубликованные** - уже опубликованные посты

### Детали поста

При просмотре конкретного поста вы увидите:
- Статус поста (черновик, запланирован, опубликован)
- Дату планирования или публикации
- Полный текст контента
- Хештеги (если есть)

**Доступные действия:**
- **📤 Опубликовать** - для черновиков
- **⏰ Запланировать** - для черновиков
- **❌ Отменить публикацию** - для запланированных
- **✏️ Редактировать** - изменить пост
- **🗑️ Удалить** - удалить пост (требует подтверждения)

## 📈 Аналитика

### Просмотр статистики

1. Откройте меню **Аналитика**
2. Выберите канал
3. Просмотрите метрики:
   - 👁️ Просмотры
   - ❤️ Реакции
   - 📤 Репосты
   - 💬 Комментарии
   - 📊 Вовлеченность (%)

### Топ постов

В аналитике отображаются:
- 3 самых популярных поста
- Количество просмотров каждого
- Период статистики

### Детальный отчет

1. В меню аналитики нажмите **Детальный отчет**
2. Бот сгенерирует полный отчет
3. Отчет включает:
   - Графики (если доступно)
   - Подробную статистику
   - Рекомендации

## ⚙️ Настройки

### Частота публикаций

1. Откройте меню **Настройки**
2. Выберите **📅 Частота публикаций**
3. Укажите количество постов в день (1-24)
4. Рекомендуется: 2-5 постов в день

### Стиль контента

1. Откройте меню **Настройки**
2. Выберите **🎨 Стиль контента**
3. Выберите стиль:
   - **Профессиональный** - деловой тон
   - **Неформальный** - casual стиль
   - **Юмористический** - с шутками

### Уведомления

1. Откройте меню **Настройки**
2. Выберите **🔔 Уведомления**
3. Включите/выключите категории:
   - Ошибки и проблемы
   - Завершение публикаций
   - Важные события
   - Еженедельная аналитика

### Язык интерфейса

1. Откройте меню **Настройки**
2. Выберите **🌐 Язык**
3. Выберите язык интерфейса

## 🆘 Помощь и поддержка

### Контекстная помощь

В любом меню нажмите **❓ Помощь** для получения информации о текущем разделе.

### Отмена операции

Во время диалога (добавление канала, ввод темы):
- Отправьте `/cancel` для отмены
- Автоматически вернётесь в предыдущее меню (например, меню каналов после отмены регистрации)

### Возврат в главное меню

- Используйте кнопку **⬅️ Назад** в любом меню
- Отправьте `/start` для перезапуска

### Таймаут диалога

Если вы не отвечаете 5 минут:
- Диалог автоматически завершится
- Вы получите уведомление
- Данные не сохранятся

## ❓ Часто задаваемые вопросы

### Как добавить бота в канал?

1. Откройте настройки канала в Telegram
2. Перейдите в "Администраторы"
3. Нажмите "Добавить администратора"
4. Найдите вашего бота
5. Дайте права на публикацию сообщений

### Почему бот не может опубликовать пост?

Возможные причины:
- Бот не является администратором канала
- У бота нет прав на публикацию
- Канал недоступен или удален
- Проверьте права бота в настройках канала

### Как изменить тему по умолчанию?

Тема по умолчанию: "актуальные новости и тренды"
Для изменения используйте меню **Настройки** (в разработке)

### Сколько постов можно генерировать?

Ограничений нет, но рекомендуется:
- 2-5 постов в день для качественного контента
- Не более 24 постов в день (настройка)

### Как удалить опубликованный пост?

Бот не удаляет посты автоматически.
Для удаления:
1. Откройте канал в Telegram
2. Найдите пост
3. Удалите вручную как администратор

### Что делать при ошибке?

1. Прочитайте сообщение об ошибке
2. Следуйте подсказкам бота
3. Попробуйте операцию снова
4. Если ошибка повторяется - обратитесь к администратору

## 🔒 Безопасность и конфиденциальность

### Какие данные хранятся?

- ID ваших каналов
- Названия каналов
- История сгенерированных постов
- Настройки бота

### Доступ к каналам

Бот имеет доступ только к каналам, где он является администратором.
Бот не может:
- Читать личные сообщения
- Получать доступ к другим каналам
- Изменять права администраторов

### Удаление данных

Для удаления всех данных:
1. Удалите все каналы через меню
2. Обратитесь к администратору бота
