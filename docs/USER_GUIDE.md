# Руководство пользователя Telegram-бота

## Обзор возможностей

Telegram-бот предоставляет следующие основные функции:

- Автоматическая публикация контента в каналах (autopost)
- Интеграция с языковыми моделями (LLM)
- Анализ статистики каналов
- Управление каналами и постами
- Настройка расписания публикаций
- Интерактивное меню с кнопками
- Система модерации контента
- Многоуровневое кэширование
- Мониторинг и логирование

## Основные команды

### Команды управления

- `/start` - начать взаимодействие с ботом
- `/help` - получить справку о доступных командах
- `/status` - показать статус системы
- `/config` - настройки бота
- `/theme <тема>` - установить тему контента
- `/register <channel_id> <name>` - зарегистрировать канал
- `/generate <channel_id> <theme>` - сгенерировать пост
- `/stop` - остановить все операции (только для админов)

### Команды автопостинга

- `/autopost_add_channel` - добавить канал для автопостинга
- `/autopost_remove_channel` - удалить канал из автопостинга
- `/autopost_list_channels` - список всех каналов
- `/autopost_generate` - сгенерировать пост для автопостинга
- `/autopost_approve` - одобрить пост для публикации
- `/autopost_queue` - просмотр очереди постов
- `/autopost_schedule` - настроить расписание публикаций
- `/autopost_list_schedules` - список расписаний
- `/autopost_stats` - статистика автопостинга
- `/autopost_set_moderation` - включить/выключить модерацию
- `/autopost_set_frequency` - установить частоту публикаций
- `/autopost_help` - справка по автопостингу

### Команды LLM

- `/llm_status` - статус LLM системы
- `/llm_stats` - статистика использования LLM
- `/llm_switch` - переключить провайдера LLM
- `/llm_models` - доступные модели LLM
- `/llm_set_model` - установить модель по умолчанию
- `/llm_cache_clear` - очистить кэш LLM
- `/llm_test` - тест генерации
- `/llm_monitoring` - мониторинг провайдеров
- `/llm_config` - конфигурация LLM
- `/llm_rate_limit` - управление лимитами запросов
- `/llm_help` - справка по LLM

## Интерактивное меню

Бот предоставляет удобное интерактивное меню с кнопками для всех основных функций:

### Главное меню
- **Каналы** - управление каналами

- **Аналитика** - статистика и отчеты
- **Настройки** - конфигурация бота
- **Быстрые действия** - генерация поста и проверка статуса

### Управление каналами
- **Добавить канал** - регистрация нового канала
- **Список каналов** - просмотр зарегистрированных каналов
- **Создать пост** - создание поста для канала
- **Расписание** - настройка автоматических публикаций
- **Настроить** - изменение параметров канала
- **Аналитика** - статистика по каналу
- **Удалить** - удаление канала из системы

### Управление контентом
- **Сгенерировать** - создание нового поста
- **Запланировать** - настройка расписания публикаций
- **Просмотр постов** - список созданных постов
- **Очередь** - управление очередью публикаций

### Настройки
- **Частота публикаций** - количество постов в день
- **Стиль контента** - тон и формат генерации
- **Уведомления** - настройка оповещений
- **Язык интерфейса** - выбор языка
- **Кэширование** - настройки кэша LLM
- **Лимиты** - ограничения запросов

## Настройка автопостинга

### Добавление канала

1. Добавьте бота в ваш Telegram-канал как администратора с правами на публикацию сообщений
2. В личных сообщениях с ботом выполните команду `/autopost_add_channel`
3. Укажите ID канала и название:
   ```
   /autopost_add_channel -1001234567890 'Название моего канала'
   ```
4. При необходимости укажите частоту публикаций (по умолчанию 3 поста в день)

### Настройка источника контента

Система автопостинга поддерживает различные источники контента:

- RSS-ленты
- Веб-страницы
- API сторонних сервисов
- Встроенные шаблоны
- Ручной ввод тем

Для настройки источника используйте команду `/autopost_generate` с указанием темы.

### Планирование публикаций

Система позволяет настраивать расписание публикаций:

- **Фиксированное время** - публикации в заданное время
- **Случайное время** - публикации с случайным интервалом
- **Интервальное** - публикации с фиксированным интервалом

Для настройки расписания используйте команду:
```
/autopost_schedule -1001234567890 09:00,15:00,21:00
```

### Модерация контента

Вы можете включить модерацию для каналов, чтобы проверять и одобрять посты перед публикацией:
```
/autopost_set_moderation -1001234567890 on
```

## Использование LLM

### Выбор провайдера

Бот поддерживает несколько провайдеров LLM:

- **Groq** - быстрые ответы, рекомендуется
- **Google Gemini** - высококачественный контент
- **Hugging Face** - резервный провайдер

Для переключения провайдера используйте команду:
```
/llm_switch groq
```

### Генерация контента

Для тестирования генерации используйте команду:
```
/llm_test Напиши приветствие 0.7 150
```

Где:
- `Напиши приветствие` - промпт
- `0.7` - температура (0.0-2.0)
- `150` - максимальное количество токенов

### Управление кэшем

Для очистки кэша LLM используйте:
```
/llm_cache_clear
```

## Анализ статистики

### Статистика каналов

- `/autopost_stats` - статистика автопостинга

### Экспорт данных

Данные статистики могут быть экспортированы в различных форматах:

- CSV
- JSON
- Текстовый формат


- **Отклонить** - отменить публикацию

## Устранение неполадок

### Бот не отвечает

1. Проверьте подключение к интернету
2. Убедитесь, что бот не заблокирован
3. Проверьте настройки прокси (если используются)
4. Перезапустите бота
5. Проверьте логи в папке `logs/`

### Проблемы с автопостингом

1. Убедитесь, что бот является администратором канала
2. Проверьте права на публикацию сообщений
3. Проверьте настройки источника контента
4. Убедитесь, что канал активен в системе
5. Проверьте расписание публикаций

### Проблемы с LLM

1. Проверьте наличие API-ключей
2. Убедитесь, что лимиты не исчерпаны
3. Проверьте настройки подключения
4. Попробуйте переключиться на другой провайдер
5. Очистите кэш LLM

### Проблемы с базой данных

1. Проверьте строку подключения
2. Убедитесь, что база данных доступна
3. Запустите скрипт инициализации
4. Проверьте права доступа

## Безопасность

- Не делитесь токеном бота с другими
- Регулярно меняйте API-ключи
- Ограничьте права бота в каналах до необходимого минимума
- Мониторьте логи на предмет подозрительной активности
- Используйте ограничения частоты запросов
- Проверяйте пользовательский ввод на безопасность

## Продвинутые функции

### Настройка через .env файл

Для продвинутой настройки используйте файл `.env`:

- Настройка API-ключей
- Конфигурация базы данных
- Параметры кэширования
- Настройки безопасности
- Параметры мониторинга

### Docker-развертывание

Для продакшена рекомендуется использовать Docker:

1. Настройте `docker-compose.yml`
2. Обновите файл `.env`
3. Запустите `docker-compose up --build`
