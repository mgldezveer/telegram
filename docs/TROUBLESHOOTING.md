# 🔧 Руководство по устранению неполадок

## 🚨 Общие проблемы

### Бот не отвечает

**Симптомы:**
- Бот не реагирует на команды
- Сообщения не доставляются
- Кнопки не работают

**Решения:**

1. **Проверьте статус бота**
   - Отправьте `/start`
   - Если нет ответа - бот может быть остановлен

2. **Проверьте версию Python**
   - Убедитесь, что используется Python 3.10 или выше
   - Проверьте: `python --version`
   - Python 3.9 и ниже больше не поддерживаются

3. **Проверьте интернет-соединение**
   - Убедитесь, что у вас есть доступ к Telegram
   - Попробуйте открыть другие чаты

4. **Проверьте Redis подключение**
   - Если используется Redis, убедитесь что он запущен
   - Проверьте: `redis-cli ping` (должен вернуть PONG)
   - Бот может работать медленнее без Redis

5. **Перезапустите диалог**
   - Отправьте `/start` снова
   - Попробуйте через несколько минут

6. **Обратитесь к администратору**
   - Если проблема сохраняется более 5 минут

## ⚙️ Проблемы с инфраструктурой

### Предупреждения о версии Python

**Предупреждение:** "Python 3.9 is deprecated. Please upgrade to Python 3.10 or higher."

**Причина:**
- Python 3.9 больше не получает обновления безопасности
- Некоторые зависимости требуют Python 3.10+

**Решение:**

1. **Проверьте текущую версию:**
   ```bash
   python --version
   ```

2. **Установите Python 3.10 или выше:**
   
   **Windows:**
   - Скачайте с [python.org](https://www.python.org/downloads/)
   - Или используйте: `winget install Python.Python.3.11`

   **Linux:**
   ```bash
   sudo apt-get update
   sudo apt-get install python3.11
   ```

   **macOS:**
   ```bash
   brew install python@3.11
   ```

3. **Пересоздайте виртуальное окружение:**
   ```bash
   # Удалите старое окружение
   rm -rf venv
   
   # Создайте новое с Python 3.10+
   python3.11 -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   
   # Переустановите зависимости
   pip install -r requirements.txt
   ```

### Проблемы с Redis

**Предупреждение:** "Failed to connect to Redis. Using fallback in-memory cache."

**Причины и решения:**

1. **Redis не установлен**
   
   **Решение:**
   
   **Windows:**
   ```powershell
   # Используя Chocolatey
   choco install redis-64
   
   # Или Docker
   docker run -d -p 6379:6379 --name redis redis:7-alpine
   ```
   
   **Linux:**
   ```bash
   sudo apt-get update
   sudo apt-get install redis-server
   sudo systemctl start redis-server
   ```
   
   **macOS:**
   ```bash
   brew install redis
   brew services start redis
   ```

2. **Redis не запущен**
   
   **Проверка:**
   ```bash
   redis-cli ping
   # Должен вернуть: PONG
   ```
   
   **Запуск:**
   ```bash
   # Linux
   sudo systemctl start redis-server
   
   # macOS
   brew services start redis
   
   # Docker
   docker start redis
   
   # Windows (если установлен локально)
   redis-server
   ```

3. **Неверные параметры подключения**
   
   **Проверьте .env файл:**
   ```bash
   # Базовая конфигурация
   REDIS_URL=redis://localhost:6379/0
   
   # Или отдельные параметры
   REDIS_HOST=localhost
   REDIS_PORT=6379
   REDIS_PASSWORD=  # Если требуется
   REDIS_DB=0
   ```

4. **Порт 6379 занят**
   
   **Проверка:**
   ```bash
   # Linux/macOS
   netstat -an | grep 6379
   
   # Windows
   netstat -an | findstr 6379
   ```
   
   **Решение:**
   - Остановите другое приложение на порту 6379
   - Или измените порт Redis в конфигурации

5. **Firewall блокирует подключение**
   
   **Решение:**
   ```bash
   # Linux
   sudo ufw allow 6379
   
   # Windows
   # Добавьте правило в Windows Firewall для порта 6379
   ```

**Важно:** Бот продолжит работать без Redis, используя кэш в памяти, но:
- Производительность может быть ниже
- Кэш не сохраняется между перезапусками
- Расходы на API могут быть выше

### Предупреждения ConversationHandler

**Предупреждение:** "PTBUserWarning: If 'per_message=False', 'CallbackQueryHandler' will not be tracked..."

**Причина:**
- Неправильная конфигурация ConversationHandler
- Устаревшая версия кода

**Решение:**

1. **Обновите код:**
   ```bash
   git pull
   ```

2. **Перезапустите бота:**
   ```bash
   # Docker
   docker-compose restart bot
   
   # Локально
   python run.py
   ```

3. **Проверьте логи:**
   - Предупреждение должно исчезнуть
   - Если осталось - сообщите администратору

### Проблемы с производительностью

**Симптомы:**
- Медленные ответы бота
- Задержки при генерации контента
- Высокие расходы на API

**Решения:**

1. **Установите и настройте Redis**
   - См. раздел "Проблемы с Redis" выше
   - Redis значительно ускоряет работу

2. **Проверьте кэширование:**
   ```bash
   # В .env файле
   LLM_CACHE_ENABLED=true
   LLM_CACHE_TTL=3600
   ```

3. **Увеличьте размер кэша:**
   ```bash
   LLM_CACHE_MAX_SIZE=5000
   ```

4. **Проверьте использование ресурсов:**
   ```bash
   # Проверка здоровья
   curl http://localhost:9090/health
   ```

## 📊 Проблемы с каналами

### Не могу добавить канал

**Ошибка:** "Не удалось получить доступ к каналу"

**Причины и решения:**

1. **Неверный ID канала**
   - ✅ Проверьте формат: `-1001234567890`
   - ✅ ID должен быть отрицательным числом
   - ✅ Используйте @userinfobot для получения ID

2. **Бот не добавлен в канал**
   - ✅ Откройте настройки канала
   - ✅ Добавьте бота как администратора
   - ✅ Попробуйте снова

3. **Недостаточно прав**
   - ✅ Проверьте права бота в канале
   - ✅ Включите "Публикация сообщений"
   - ✅ Сохраните изменения

**Ошибка:** "ID канала должен быть отрицательным числом"

**Решение:**
- Вы ввели ID пользователя или группы вместо канала
- Используйте ID канала (начинается с `-100`)
- Пример правильного ID: `-1001234567890`

### Канал не отображается в списке

**Причины:**

1. **Канал был удален**
   - Проверьте, существует ли канал в Telegram
   - Добавьте канал заново

2. **Ошибка загрузки**
   - Вернитесь в главное меню
   - Откройте раздел "Каналы" снова

3. **Канал не зарегистрирован**
   - Убедитесь, что регистрация завершилась успешно
   - Проверьте сообщение о подтверждении

### Не могу удалить канал

**Ошибка:** "Ошибка при удалении канала"

**Решения:**

1. **Попробуйте снова**
   - Нажмите "Удалить" еще раз
   - Подтвердите удаление в диалоге подтверждения

2. **Проверьте подключение**
   - Убедитесь в стабильном интернете
   - Попробуйте через минуту

3. **Обратитесь к администратору**
   - Если ошибка повторяется

**Примечание:** Удаление канала или поста требует подтверждения для предотвращения случайного удаления. Всегда внимательно читайте предупреждения перед подтверждением.

## ✍️ Проблемы с генерацией контента

### Генерация не запускается

**Ошибка:** "Нет доступных каналов"

**Решение:**
- Сначала добавьте хотя бы один канал
- Перейдите в меню "Каналы"
- Нажмите "Добавить канал"

**Ошибка:** "Сервис генерации недоступен"

**Решения:**

1. **Подождите**
   - Сервис может быть временно недоступен
   - Попробуйте через 1-2 минуты

2. **Используйте другую тему**
   - Попробуйте предустановленную тему
   - Измените формулировку кастомной темы

3. **Обратитесь к администратору**
   - Если проблема сохраняется более 5 минут

### Генерация зависла

**Симптомы:**
- Сообщение "Генерирую..." более 2 минут
- Нет ответа от бота

**Решения:**

1. **Подождите**
   - Генерация может занять до 30 секунд
   - Не отправляйте новые команды

2. **Отмените операцию**
   - Отправьте `/cancel`
   - Вернитесь в главное меню

3. **Попробуйте снова**
   - Запустите генерацию заново
   - Используйте более простую тему

### Пост не соответствует теме

**Проблема:** Сгенерированный пост не по теме

**Решения:**

1. **Уточните тему**
   - Используйте более конкретную формулировку
   - Добавьте детали и контекст
   - ❌ "технологии"
   - ✅ "новые функции Python 3.12"

2. **Регенерируйте пост**
   - Нажмите "🔄 Перегенерировать"
   - Попробуйте несколько раз

3. **Измените стиль**
   - Перейдите в "Настройки"
   - Выберите другой стиль контента

### Не могу опубликовать пост

**Ошибка:** "Не удалось опубликовать пост"

**Причины и решения:**

1. **Бот потерял права**
   - ✅ Проверьте, что бот все еще администратор
   - ✅ Проверьте права на публикацию
   - ✅ Переназначьте права если нужно

2. **Канал недоступен**
   - ✅ Откройте канал в Telegram
   - ✅ Убедитесь, что канал существует
   - ✅ Проверьте, не заблокирован ли канал

3. **Проблема с контентом**
   - ✅ Пост может нарушать правила Telegram
   - ✅ Попробуйте регенерировать
   - ✅ Используйте другую тему

## 🔄 Проблемы с диалогами

### Диалог прервался

**Симптомы:**
- Бот перестал отвечать во время диалога
- Получено сообщение о таймауте

**Причины:**

1. **Таймаут (5 минут)**
   - Вы не отвечали более 5 минут
   - Диалог автоматически завершен

2. **Отправлена команда**
   - Команды прерывают диалоги
   - Используйте `/cancel` для отмены

**Решение:**
- Начните операцию заново
- Отвечайте быстрее (в течение 5 минут)

### Не могу отменить операцию

**Проблема:** `/cancel` не работает

**Решения:**

1. **Используйте кнопку**
   - Нажмите "❌ Отмена" если есть
   - Используйте "⬅️ Назад"

2. **Отправьте `/start`**
   - Это перезапустит бота
   - Вернет в главное меню

3. **Дождитесь таймаута**
   - Через 5 минут диалог завершится автоматически

### Ввод не принимается

**Ошибка:** "Неверный формат" или "Слишком короткое"

**Решения по типу ввода:**

**ID канала:**
- Должен быть числом
- Должен быть отрицательным
- Пример: `-1001234567890`

**Название канала:**
- Минимум 2 символа
- Максимум 100 символов
- Без спецсимволов

**Тема контента:**
- Минимум 3 символа
- Максимум 200 символов
- Без чрезмерных повторений

## ⚙️ Проблемы с настройками

### Настройки не сохраняются

**Проблема:** После изменения настройки возвращаются к старым

**Решения:**

1. **Проверьте подтверждение**
   - Дождитесь сообщения "Настройки сохранены"
   - Не закрывайте меню сразу

2. **Попробуйте снова**
   - Измените настройку еще раз
   - Проверьте, что изменение применилось

3. **Перезапустите бота**
   - Отправьте `/start`
   - Проверьте настройки снова

### Неверное значение настройки

**Ошибка:** "Частота должна быть от 1 до 24"

**Решение:**
- Введите число в допустимом диапазоне
- Для частоты: 1-24
- Рекомендуется: 2-5

**Решения:**

   - Откройте снова

2. **Подождите**

   - Telegram предоставляет данные с задержкой
