# MultiLevelCache - Многоуровневый кэш

## Обзор

`MultiLevelCache` - это реализация многоуровневого кэша, поддерживающая несколько уровней хранения данных с разными характеристиками производительности и надежности. Основная идея заключается в использовании быстрых, но менее надежных уровней (например, память) в сочетании с медленными, но более надежными уровнями (например, Redis или база данных).

## Архитектура

### Уровни кэша (CacheLevel)

Каждый уровень кэша представлен классом `CacheLevel`, который содержит:

- `name`: Название уровня
- `cache_instance`: Экземпляр кэша (должен реализовывать интерфейс `ICache`)
- `priority`: Приоритет уровня (меньше число - выше приоритет)
- `default_ttl`: Время жизни по умолчанию для уровня

### Стратегии синхронизации

Класс поддерживает три стратегии синхронизации между уровнями:

1. **Write-through** (по умолчанию): данные записываются во все уровни одновременно
2. **Write-back**: данные записываются только в самый быстрый уровень, остальные обновляются позже
3. **Write-around**: данные записываются только в самый медленный уровень, исключая более быстрые уровни

## Основные методы

### Инициализация

```python
cache = MultiLevelCache()
await cache.initialize()
```

Можно также передать кастомные уровни:

```python
levels = [
    CacheLevel("redis", RedisCache(), 0, default_ttl=300),
    CacheLevel("memory", MemoryCache(), 1, default_ttl=600)
]
cache = MultiLevelCache(levels=levels, sync_strategy="write_through")
await cache.initialize()
```

### Основные операции

#### Получение и установка значений

```python
# Установка значения
await cache.set("key", "value", ttl=300)

# Получение значения
value = await cache.get("key")

# Проверка существования
exists = await cache.exists("key")

# Удаление значения
await cache.delete("key")
```

#### Операции с хэшами

```python
# Установка значения в хэш
await cache.hset("hash_name", "field", "value", ttl=300)

# Получение значения из хэша
value = await cache.hget("hash_name", "field")

# Получение всех полей хэша
all_fields = await cache.hgetall("hash_name")

# Удаление полей из хэша
deleted_count = await cache.hdel("hash_name", "field1", "field2")
```

#### Множественные операции

```python
# Получение нескольких значений
values = await cache.mget(["key1", "key2", "key3"])

# Установка нескольких значений
await cache.mset({"key1": "value1", "key2": "value2"}, ttl=300)
```

### Специфические методы многоуровневого кэша

#### Управление уровнями

```python
# Добавление уровня
await cache.add_level("new_level", new_cache_instance, priority=2, default_ttl=900)

# Удаление уровня
await cache.remove_level("level_name")

# Проверка статуса уровней
status = cache.get_level_status()

# Проверка доступности конкретного уровня
is_available = cache.is_level_available("redis")
```

#### Получение статистики

```python
stats = await cache.get_stats()
```

## Принцип работы

### Чтение данных

1. При чтении данных система проверяет уровни в порядке приоритета (от самого быстрого к самому медленному)
2. Если значение найдено в более медленном уровне, оно автоматически записывается в более быстрые уровни для ускорения будущих обращений (cache warming)
3. Возвращается первое найденное значение

### Запись данных

В зависимости от стратегии синхронизации:

- **Write-through**: данные записываются во все доступные уровни сразу
- **Write-back**: данные записываются только в самый быстрый уровень
- **Write-around**: данные записываются только в самый медленный уровень

### Обработка ошибок

- Если один из уровней недоступен, система продолжает работу с оставшимися уровнями
- Ошибки логируются, и уровень помечается как недоступный до следующей проверки
- При восстановлении уровня он автоматически включается в работу

## Преимущества

1. **Высокая производительность**: часто используемые данные хранятся в быстрых уровнях
2. **Надежность**: при выходе из строя одного уровня система продолжает работу
3. **Гибкость**: поддержка различных стратегий синхронизации
4. **Масштабируемость**: легко добавлять новые уровни кэша
5. **Автоматическое управление**: данные автоматически перемещаются между уровнями

## Примеры использования

### Простое использование

```python
from src.cache.multi_level_cache import MultiLevelCache

cache = MultiLevelCache()
await cache.initialize()

# Использование как обычный кэш
await cache.set("user:123", {"name": "John", "email": "john@example.com"}, ttl=3600)
user_data = await cache.get("user:123")
```

### Использование с кастомными уровнями

```python
from src.cache.multi_level_cache import MultiLevelCache, CacheLevel
from src.cache.memory_cache import MemoryCache
from src.cache.redis_cache import RedisCache

# Определяем уровни: L1 (очень быстрый, маленький) -> L2 (быстрый, средний) -> L3 (медленный, большой)
levels = [
    CacheLevel("l1_cache", MemoryCache(max_size=100, default_ttl=60), 0),
    CacheLevel("l2_cache", MemoryCache(max_size=100, default_ttl=300), 1),
    CacheLevel("l3_cache", RedisCache(), 2, default_ttl=3600)
]

cache = MultiLevelCache(levels=levels, sync_strategy="write_through")
await cache.initialize()
```

## Рекомендации по использованию

1. Используйте стратегию `write-through` для данных, где важна согласованность
2. Используйте стратегию `write-back` для данных, к которым часто идет запись
3. Используйте стратегию `write-around` для данных, которые не часто читаются после записи
4. Правильно настраивайте TTL для разных уровней (меньше для быстрых уровней, больше для медленных)
5. Мониторьте статус уровней и при необходимости добавляйте резервные уровни
