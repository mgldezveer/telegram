## 🚀 Как начать использовать

### 1. Откройте Telegram
Найдите вашего бота и отправьте команду `/start`

### 2. Основные команды

```
/start   - Запустить бота
/help    - Показать справку
/status  - Проверить статус
/config  - Настроить параметры
/generate - Сгенерировать тестовый пост
/stop    - Остановить бота
```

### 3. Первая настройка

1. Отправьте `/config` для настройки:
   - Частота публикаций (по умолчанию: 3 поста в день)
   - Темы контента
   - Стиль написания

2. Добавьте канал для публикаций

3. Настройте расписание

### 4. Тестовая генерация

Попробуйте сгенерировать пост:
```
/generate технологии
```

Бот создаст пост на тему технологий с использованием AI.
