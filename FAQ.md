# Frequently Asked Questions (FAQ)

## General Questions

### Q: Что делает этот бот?
**A:** AI Content Bot автоматически генерирует и публикует контент в ваши Telegram каналы используя AI (Groq API с моделью Qwen 2.5). Он может:
- Генерировать посты на любую тему
- Планировать публикации
- Оптимизировать контент для engagement
- Собирать аналитику
- Управлять несколькими каналами

### Q: Сколько это стоит?
**A:** Сам бот бесплатный (open source). Вам нужно только:
- Groq API ключ (есть бесплатный tier)
- Сервер для запуска (можно на своем компьютере)

### Q: Нужны ли мне технические знания?
**A:** Базовые знания:
- Умение запускать Python скрипты
- Понимание как работают Telegram боты
- Базовые навыки работы с командной строкой

## Setup & Installation

### Q: Какая версия Python нужна?
**A:** Python 3.11 или выше. Проверьте: `python --version`

### Q: Где взять Telegram Bot Token?
**A:** 
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

### Q: Где взять Groq API Key?
**A:**
1. Зарегистрируйтесь на https://console.groq.com
2. Перейдите в API Keys
3. Создайте новый ключ
4. Скопируйте его в `.env`

### Q: Как узнать мой Telegram User ID?
**A:** Отправьте любое сообщение боту [@userinfobot](https://t.me/userinfobot)

### Q: Можно ли использовать OpenAI вместо Groq?
**A:** Да! В `src/services/content_generator.py` замените Groq клиент на OpenAI:
```python
from openai import AsyncOpenAI
client = AsyncOpenAI(api_key=config.ai.api_key)
```

## Channel Management

### Q: Как добавить канал?
**A:** 
1. Сделайте бота администратором канала
2. Отправьте: `/add_channel @channel_name category`

### Q: Бот не может публиковать в канал
**A:** Проверьте:
- Бот добавлен как администратор?
- У бота есть права на публикацию?
- Правильный ли username канала (с @)?

### Q: Как узнать ID канала?
**A:** Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)

### Q: Можно ли управлять несколькими каналами?
**A:** Да! Добавьте каждый канал отдельно командой `/add_channel`

### Q: Как удалить канал?
**A:** Пока нет команды, но можно удалить из базы данных:
```bash
sqlite3 bot.db "DELETE FROM channels WHERE id=1;"
```

## Content Generation

### Q: На каких языках бот может генерировать контент?
**A:** На любых! Модель Qwen 2.5 поддерживает множество языков. Просто укажите тему на нужном языке:
- `/generate tech "AI trends"` - английский
- `/generate tech "Тренды ИИ"` - русский

### Q: Как контролировать качество контента?
**A:** Бот использует Quality Control систему:
- Проверка длины (не слишком короткий/длинный)
- Фильтрация запрещенных слов
- Проверка релевантности теме
- Оптимизация для engagement

### Q: Можно ли настроить стиль контента?
**A:** Да, в `src/services/content_generator.py` измените system prompt:
```python
system_prompt = "You are a professional content writer with a casual, friendly tone..."
```

### Q: Сколько времени занимает генерация?
**A:** Обычно 5-15 секунд, в зависимости от:
- Загрузки Groq API
- Сложности темы
- Длины контента

### Q: Можно ли генерировать изображения?
**A:** В текущей версии нет, но можно добавить интеграцию с:
- DALL-E
- Stable Diffusion
- Midjourney API

## Scheduling & Publishing

### Q: Как запланировать пост?
**A:** 
```
/schedule <post_id> <time>
```
Примеры:
- `/schedule 1 14:00` - сегодня в 14:00
- `/schedule 1 tomorrow 10:00` - завтра в 10:00

### Q: Можно ли настроить автоматическую публикацию?
**A:** Да! Используйте Celery beat для периодических задач. Настройте в `src/tasks.py`

### Q: Что если пост не опубликовался?
**A:** Бот автоматически повторит попытку (3 раза с exponential backoff). Проверьте логи для деталей.

### Q: Можно ли отменить запланированный пост?
**A:** Пока нет команды, но можно удалить из БД или изменить статус на 'cancelled'

## Analytics

### Q: Какую аналитику собирает бот?
**A:** 
- Просмотры постов
- Engagement rate
- Лучшее время для публикации
- Популярные темы
- Рост подписчиков

### Q: Как посмотреть аналитику?
**A:** `/analytics <channel_id>`

### Q: Можно ли экспортировать данные?
**A:** Да, данные в SQLite/PostgreSQL. Используйте SQL запросы или создайте export команду.

## Technical Issues

### Q: Бот не запускается
**A:** Проверьте:
1. `python check_setup.py` - все ли настроено?
2. Логи в консоли - какая ошибка?
3. `.env` файл - все ли переменные заполнены?

### Q: Ошибка "Module not found"
**A:** Установите зависимости: `pip install -r requirements.txt`

### Q: Ошибка базы данных
**A:** Переинициализируйте: `python init_db.py`

### Q: Бот медленно отвечает
**A:** Возможные причины:
- Медленный интернет
- Groq API перегружен
- Недостаточно ресурсов на сервере

### Q: Ошибка "Rate limit exceeded"
**A:** Вы превысили лимит Groq API. Подождите или обновите план.

### Q: Как посмотреть логи?
**A:** 
- Локально: смотрите в консоль
- Docker: `docker-compose logs -f bot`
- Файл: настройте в `src/logging_config.py`

## Performance & Scaling

### Q: Сколько каналов может обслуживать бот?
**A:** Зависит от:
- Частоты публикаций
- Ресурсов сервера
- Лимитов API

Обычно 10-50 каналов без проблем.

### Q: Можно ли запустить несколько ботов?
**A:** Да! Каждый с отдельной БД и конфигом.

### Q: Как масштабировать для большой нагрузки?
**A:** 
1. Используйте PostgreSQL вместо SQLite
2. Настройте Redis для кэширования
3. Используйте Celery для фоновых задач
4. Запустите несколько worker процессов

### Q: Нужен ли мне VPS?
**A:** Для production - да. Для тестирования можно на локальном компьютере.

## Customization

### Q: Как изменить AI модель?
**A:** В `.env` измените:
```
AI_MODEL=llama-3.1-70b-versatile
```
Доступные модели: https://console.groq.com/docs/models

### Q: Как добавить новые команды?
**A:** В `src/bot/controller.py` добавьте:
```python
async def my_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text("My response")

application.add_handler(CommandHandler("mycommand", my_command))
```

### Q: Как изменить формат постов?
**A:** Измените prompt в `src/services/content_generator.py`

### Q: Можно ли добавить кнопки к постам?
**A:** Да! В `src/services/publishing_service.py` добавьте InlineKeyboardMarkup

## Security

### Q: Безопасно ли хранить токены в .env?
**A:** Для локального использования - да. Для production используйте:
- Переменные окружения сервера
- Secrets manager (AWS Secrets Manager, etc.)
- Encrypted storage

### Q: Кто может использовать бота?
**A:** Только пользователи с ID в `ADMIN_IDS` могут использовать административные команды.

### Q: Как защитить от спама?
**A:** Бот уже имеет rate limiting. Настройте в `src/services/error_handler.py`

## Deployment
