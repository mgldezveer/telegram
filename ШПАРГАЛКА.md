## ⚡ Быстрый старт

### Запуск бота
```bash
python run.py
```

```bash
Ctrl+C
```

## 🔧 Конфигурация (.env)

```bash
# Telegram
TELEGRAM_BOT_TOKEN=your_token
ADMIN_IDS=your_id

# AI
GROQ_API_KEY=your_key
AI_MODEL=qwen-2.5-72b-instruct

# База данных
DATABASE_URL=sqlite:///bot.db

# Redis (опционально)
REDIS_URL=redis://localhost:6379/0

# Мониторинг
MONITORING_PORT=9090
LOG_LEVEL=INFO
```

## 🐛 Решение проблем

### Бот не запускается
1. Проверьте `.env` файл
2. Проверьте токен бота
3. Проверьте логи: `logs/bot.log`

### Порт занят
```bash
# Windows
netstat -ano | findstr :9090
taskkill /F /PID <PID>

# Linux/Mac
lsof -i :9090
kill -9 <PID>
```

### Redis недоступен
Это нормально для dev режима. Бот работает без кеша.

### Ошибки в логах
Проверьте:
1. Токен бота корректный
2. API ключ Groq корректный
3. База данных доступна

## 🎯 Типичные задачи

### Добавить канал
1. Добавьте бота в канал как админа
2. Используйте `/config` для настройки

### Изменить частоту публикаций
1. Отправьте `/config`
2. Выберите "Частота публикаций"
3. Укажите количество постов в день

### Сгенерировать тестовый пост
```
/generate технологии
```

### Проверить статистику
```
/status
```

## 📈 Мониторинг

### Основные метрики
- `posts_generated_total` - Сгенерировано постов
- `posts_published_total` - Опубликовано постов
- `posts_failed_total` - Неудачных попыток
- `active_channels` - Активных каналов
- `queue_size` - Размер очереди

### Просмотр метрик
```bash
curl http://localhost:9090/metrics | grep posts
```
