# Настройка реальной статистики из Telegram

Этот бот может получать **реальную статистику** из ваших Telegram каналов, включая:
- 👁️ Просмотры постов
- ❤️ Реакции
- 📤 Репосты (forwards)
- 👥 Количество подписчиков
- 📊 Engagement rate
- ⏰ Лучшее время для публикации

## Шаг 1: Получите API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите с помощью вашего номера телефона
3. Создайте новое приложение (если еще не создали)
4. Скопируйте **API ID** и **API Hash**

## Шаг 2: Настройте .env файл

Добавьте в ваш `.env` файл:

```env
# Telethon Configuration
TELEGRAM_API_ID=your_api_id_here
TELEGRAM_API_HASH=your_api_hash_here
```

Замените `your_api_id_here` и `your_api_hash_here` на ваши реальные значения.

## Шаг 3: Установите зависимости

```bash
pip install -r requirements.txt
```

Это установит `telethon` - библиотеку для работы с Telegram MTProto API.

## Шаг 4: Добавьте канал в бота

1. Запустите бота: `python run.py`
2. Откройте бота в Telegram
3. Используйте команду `/start`
4. Перейдите в **Каналы** → **Добавить канал**
5. Следуйте инструкциям для добавления канала

**Важно:** При добавлении канала укажите его **username** (например, `@mychannel`), а не числовой ID.

## Шаг 5: Синхронизируйте статистику

Запустите скрипт синхронизации:

```bash
python sync_channel_stats.py
```

При первом запуске Telethon попросит вас:
1. Ввести номер телефона
2. Ввести код подтверждения из Telegram
3. (Опционально) Ввести пароль двухфакторной аутентификации

После этого создастся файл сессии `bot_stats.session`, и в следующий раз авторизация не потребуется.

## Шаг 6: Просмотрите статистику

1. Откройте бота в Telegram
2. Перейдите в **Аналитика**
3. Выберите канал
4. Наслаждайтесь реальной статистикой! 📊

## Автоматическая синхронизация

Чтобы статистика обновлялась автоматически, добавьте задачу в cron (Linux/Mac) или Task Scheduler (Windows):

### Linux/Mac (cron)

```bash
# Редактировать crontab
crontab -e

# Добавить строку (обновление каждый день в 3:00)
0 3 * * * cd /path/to/bot && python sync_channel_stats.py
```

### Windows (Task Scheduler)

1. Откройте Task Scheduler
2. Создайте новую задачу
3. Триггер: Ежедневно в 3:00
4. Действие: Запустить программу
   - Программа: `python`
   - Аргументы: `sync_channel_stats.py`
   - Рабочая папка: путь к боту

## Ограничения

### Что можно получить:
- ✅ Просмотры постов
- ✅ Реакции
- ✅ Репосты (forwards)
- ✅ Количество подписчиков (если бот админ)
- ✅ Дата и время публикации

### Что нельзя получить через API:
- ❌ Комментарии (требуется отдельная обработка)
- ❌ Детальная демография подписчиков
- ❌ Источники трафика

## Требования к каналу

Для получения статистики канал должен быть:
- **Публичным** (имеет username)
- **Доступным** для вашего аккаунта

Если канал приватный, ваш аккаунт должен быть:
- Подписан на канал, ИЛИ
- Администратором канала

## Безопасность

- ✅ Файл сессии (`bot_stats.session`) хранится локально
- ✅ API credentials хранятся в `.env` (не коммитятся в git)
- ✅ Telethon использует официальный Telegram API
- ✅ Никакие данные не передаются третьим лицам

## Troubleshooting

### "ChannelPrivateError"
Канал приватный или недоступен. Убедитесь что:
- Канал публичный (имеет @username)
- Вы подписаны на канал
- Или вы администратор канала

### "FloodWaitError"
Telegram ограничил количество запросов. Подождите указанное время.

### "SessionPasswordNeededError"
У вас включена двухфакторная аутентификация. Введите пароль при запросе.
