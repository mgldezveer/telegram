# 🆓 Настройка бесплатных LLM API

## Обзор

Этот гайд поможет вам получить **бесплатные** API ключи для трех LLM провайдеров:
- **Groq** - Самый быстрый (< 1 сек)
- **Google Gemini** - Качественный и надежный
- **Hugging Face** - Множество открытых моделей

---

## 1. Groq API (Рекомендуется) ⚡

### Почему Groq?
- ✅ **Очень быстрый** - генерация за < 1 секунду
- ✅ **Бесплатный tier** - 30 запросов в минуту
- ✅ **Качественные модели** - Llama 3 70B, Mixtral 8x7B
- ✅ **Простая регистрация** - без кредитной карты

### Как получить ключ:

1. **Перейдите на сайт:** https://console.groq.com/

2. **Зарегистрируйтесь:**
   - Нажмите "Sign Up"
   - Используйте Google/GitHub аккаунт или email
   - Подтвердите email

3. **Создайте API ключ:**
   - Перейдите в "API Keys"
   - Нажмите "Create API Key"
   - Скопируйте ключ (начинается с `gsk_...`)

4. **Добавьте в .env:**
   ```bash
   GROQ_API_KEY=gsk_ваш_ключ_здесь
   GROQ_MODEL=llama3-70b-8192
   ```

### Лимиты (бесплатно):
- 30 запросов в минуту
- 14,400 запросов в день
- Без ограничений по токенам

---

## 2. Google Gemini API 🌟

### Почему Gemini?
- ✅ **Качественная генерация** - от Google
- ✅ **Бесплатный tier** - 60 запросов в день
- ✅ **Safety controls** - встроенная модерация
- ✅ **Надежность** - стабильная работа

### Как получить ключ:

1. **Перейдите на сайт:** https://makersuite.google.com/app/apikey

2. **Войдите с Google аккаунтом**

3. **Создайте API ключ:**
   - Нажмите "Create API Key"
   - Выберите проект или создайте новый
   - Скопируйте ключ (начинается с `AIza...`)

4. **Добавьте в .env:**
   ```bash
   GEMINI_API_KEY=AIza_ваш_ключ_здесь
   GEMINI_MODEL=gemini-1.5-flash
   ```

### Лимиты (бесплатно):
- 60 запросов в минуту
- 1,500 запросов в день
- 32,000 токенов на запрос

---

## 3. Hugging Face API 🤗

### Почему Hugging Face?
- ✅ **Открытые модели** - множество вариантов
- ✅ **Бесплатный tier** - 1000 запросов в час
- ✅ **Гибкость** - можно менять модели
- ✅ **Community** - большое сообщество

### Как получить ключ:

1. **Перейдите на сайт:** https://huggingface.co/

2. **Зарегистрируйтесь:**
   - Нажмите "Sign Up"
   - Используйте email или GitHub

3. **Создайте токен:**
   - Перейдите в Settings → Access Tokens
   - Нажмите "New token"
   - Выберите "Read" permissions
   - Скопируйте токен (начинается с `hf_...`)

4. **Добавьте в .env:**
   ```bash
   HF_API_KEY=hf_ваш_токен_здесь
   HF_MODEL=mistralai/Mixtral-8x7B-Instruct-v0.1
   ```

### Лимиты (бесплатно):
- 1,000 запросов в час
- Может быть медленнее (3-6 сек)
- Зависит от загрузки модели

## 📝 Полная конфигурация .env

Создайте файл `.env` в корне проекта:

```bash
# ============================================
# БЕСПЛАТНЫЕ LLM API КЛЮЧИ
# ============================================

# Groq (Рекомендуется - самый быстрый)
GROQ_API_KEY=gsk_ваш_ключ_здесь
GROQ_MODEL=llama3-70b-8192

# Google Gemini (Качественный)
GEMINI_API_KEY=AIza_ваш_ключ_здесь
GEMINI_MODEL=gemini-1.5-flash

# Hugging Face (Открытые модели)
HF_API_KEY=hf_ваш_токен_здесь
HF_MODEL=mistralai/Mixtral-8x7B-Instruct-v0.1

# ============================================
# НАСТРОЙКИ ПРИОРИТЕТА
# ============================================

# Порядок использования провайдеров
LLM_PROVIDER_PRIORITY=groq,gemini,huggingface

# Включить/выключить провайдеры
LLM_GROQ_ENABLED=true
LLM_GEMINI_ENABLED=true
LLM_HF_ENABLED=true

# ============================================
# НАСТРОЙКИ КЭШИРОВАНИЯ
# ============================================

# Redis для кэша (если используется)
REDIS_URL=redis://localhost:6379
CACHE_TTL=3600

# ============================================
# НАСТРОЙКИ ГЕНЕРАЦИИ
# ============================================

# Максимальное количество токенов
MAX_TOKENS=1000

# Температура (0.0 - 1.0)
TEMPERATURE=0.7

# Таймаут запроса (секунды)
REQUEST_TIMEOUT=30
```

## 💡 Советы по использованию

### Оптимизация лимитов:

1. **Используйте кэширование** - экономит до 30% запросов
2. **Groq для быстрых задач** - вайбкодинг, короткие ответы
3. **Gemini для качества** - важные генерации
4. **HuggingFace как fallback** - когда другие недоступны

### Мониторинг использования:

```bash
# Проверить статус
/llm_status

# Посмотреть статистику
/llm_stats

# Переключить провайдер вручную
/llm_switch gemini
```

## ❓ Troubleshooting

### Ошибка: "Invalid API key"
- Проверьте что ключ скопирован полностью
- Убедитесь что нет лишних пробелов
- Проверьте что ключ активен на сайте провайдера

### Ошибка: "Rate limit exceeded"
- Система автоматически переключится на другой провайдер
- Подождите пока лимит сбросится
- Используйте кэширование для экономии запросов

### Медленная генерация
- Groq обычно < 1 сек
- Gemini 2-4 сек
- HuggingFace может быть 3-6 сек
- Проверьте интернет соединение

### Провайдер недоступен
- Проверьте статус: `/llm_status`
- Система автоматически использует fallback
- Проверьте логи для деталей
