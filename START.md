# 🚀 Быстрый запуск вашего бота

Ваш бот настроен и готов к запуску!

## ✅ Что уже настроено:

- ✅ Telegram Bot Token: настроен в `.env`
- ✅ Admin ID: настроен в `.env`
- ✅ AI Provider: Groq API (Qwen 2.5 72B модель) или OpenAI
- ✅ Файл .env создан с примерами
- ✅ Конфигурация с валидацией и значениями по умолчанию

## 📦 Шаг 1: Установка зависимостей

### Вариант А: С Docker (рекомендуется)

```bash
# Просто запустите:
docker-compose up -d

# Проверьте статус:
docker-compose ps

# Посмотрите логи:
docker-compose logs -f bot
```

### Вариант Б: Локально

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте (Windows)
venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python run.py
```

## 🤖 Шаг 2: Проверьте бота

1. Откройте Telegram
2. Найдите вашего бота (username который вы указали в BotFather)
3. Отправьте `/start`

Вы должны увидеть:
```
🤖 AI Content Bot

Автоматизированное управление каналами и создание контента с помощью ИИ.

Используйте /help для списка команд.
```

## 📱 Шаг 3: Добавьте канал

### 3.1 Узнайте ID вашего канала

1. Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
2. Он покажет ID канала (например: `-1001234567890`)

### 3.2 Добавьте бота в канал

1. Откройте ваш канал
2. Настройки → Администраторы → Добавить администратора
3. Найдите вашего бота и добавьте с правами публикации

### 3.3 Зарегистрируйте канал

Отправьте боту:
```
/register -1001234567890 "Название канала"
```

## ✨ Шаг 4: Сгенерируйте первый пост!

```
/generate 1 технологии
```

Бот создаст пост на тему "технологии" используя Qwen модель через Groq API!

## 🔧 Если что-то не работает

### Проблема: Бот не отвечает

```bash
# Проверьте логи
docker-compose logs bot

# Или если локально:
# Проверьте что бот запущен и нет ошибок в консоли
```

### Проблема: Ошибка Groq API

- Проверьте что ключ правильный в `.env`
- Убедитесь что у вас есть доступ к Groq API
- Проверьте лимиты на вашем аккаунте Groq

### Проблема: База данных

```bash
# Пересоздайте контейнеры
docker-compose down
docker-compose up -d
```
