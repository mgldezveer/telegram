# Тестирование AI Content Bot

## Статус бота
✅ Бот успешно запущен и работает!

## Доступные команды для тестирования

### 1. /start
Запускает бота и показывает приветственное сообщение.

**Как протестировать:**
1. Откройте Telegram
2. Найдите вашего бота по имени пользователя
3. Отправьте команду `/start`

**Ожидаемый результат:**
Бот должен ответить приветственным сообщением с описанием возможностей.

### 2. /help
Показывает список доступных команд и их описание.

**Как протестировать:**
1. Отправьте команду `/help`

**Ожидаемый результат:**
Список всех команд с описанием.

### 3. /status
Показывает текущий статус бота и статистику.

**Как протестировать:**
1. Отправьте команду `/status`

**Ожидаемый результат:**
- Статус бота (работает/остановлен)
- Количество активных каналов
- Количество запланированных постов
- Статистика генерации контента

### 4. /config
Настройка параметров генерации контента.

**Как протестировать:**
1. Отправьте команду `/config`
2. Следуйте инструкциям для настройки:
   - Частота публикаций
   - Темы контента
   - Стиль написания

**Ожидаемый результат:**
Интерактивное меню настройки с кнопками.

### 5. /generate
Генерирует тестовый пост с использованием AI.

**Как протестировать:**
1. Отправьте команду `/generate`
2. Можно добавить тему: `/generate технологии`

**Ожидаемый результат:**
Бот должен сгенерировать пост на заданную тему.

### 6. /stop
Останавливает бота (только для администраторов).

**Как протестировать:**
1. Отправьте команду `/stop`

**Ожидаемый результат:**
Бот должен корректно завершить работу.

## Проверка мониторинга

### Health Check
Откройте в браузере: http://localhost:9090/health

**Ожидаемый результат:**
```json
{
  "status": "healthy",
  "timestamp": "2025-11-24T21:00:00Z",
  "components": {
    "database": "ok",
    "cache": "degraded",
    "bot": "ok"
  }
}
```

### Metrics
Откройте в браузере: http://localhost:9090/metrics

**Ожидаемый результат:**
Prometheus метрики в текстовом формате.

## Логи

Логи сохраняются в файл: `logs/bot.log`

Для просмотра последних логов:
```bash
tail -f logs/bot.log
```

Или на Windows:
```powershell
Get-Content logs/bot.log -Tail 50 -Wait
```
