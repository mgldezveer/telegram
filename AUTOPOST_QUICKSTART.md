# 🚀 Быстрый старт - Автопостинг

## ✅ Бот запущен и готов к работе!

### Доступные команды:

#### 📋 Справка
```
/autopost_help
```

#### 📺 Управление каналами

**Добавить канал:**
```
/autopost_add_channel -1001234567890 "Название канала"
```

**Список каналов:**
```
/autopost_list_channels
```

#### 📝 Генерация контента

**Сгенерировать пост:**
```
/autopost_generate -1001234567890 технологии
```

Темы для генерации:
- технологии
- новости
- бизнес
- образование
- развлечения
- наука
- спорт

#### 📋 Очередь постов

**Просмотр очереди:**
```
/autopost_queue
```

**Очередь для конкретного канала:**
```
/autopost_queue -1001234567890
```

#### ⏰ Расписание

**Добавить расписание:**
```
/autopost_schedule -1001234567890 09:00,15:00,21:00
```

Это настроит автоматическую публикацию в 9:00, 15:00 и 21:00 каждый день.

**Примеры расписаний:**

Утро и вечер:
```
/autopost_schedule -1001234567890 08:00,20:00
```

Каждые 4 часа:
```
/autopost_schedule -1001234567890 00:00,04:00,08:00,12:00,16:00,20:00
```

Только рабочие часы:
```
/autopost_schedule -1001234567890 09:00,12:00,15:00,18:00
```

## ⚙️ Настройки канала

По умолчанию для каждого канала:
- ✅ Автопубликация включена
- ✅ Модерация отключена
- ✅ Стиль: профессиональный
- ✅ Язык: русский
- ✅ Частота: 3 поста в день

## 🔧 Требования

**Для добавления канала:**
1. Бот должен быть администратором канала
2. У бота должны быть права на публикацию сообщений

**Как добавить бота в канал:**
1. Откройте настройки канала
2. Администраторы → Добавить администратора
3. Найдите вашего бота
4. Дайте права на публикацию сообщений

## 🎨 Стили генерации

Система поддерживает разные стили:
- **professional** - Профессиональный (по умолчанию)
- **casual** - Неформальный
- **humorous** - Юмористический
- **formal** - Официальный

Форматы контента:
- **news** - Новости
- **tips** - Советы
- **story** - История
- **announcement** - Анонс

## 🐛 Troubleshooting

**Бот не может добавить канал:**
- Проверьте, что бот - администратор
- Проверьте права на публикацию
- ID канала должен начинаться с -100

**Посты не генерируются:**
- Проверьте наличие API ключей LLM
- Используйте `/llm_status` для проверки

**Расписание не работает:**
- Формат времени: HH:MM (например, 09:00)
- Время указывается в часовом поясе сервера
