## 🚀 Как использовать

### 1. Настройка

```bash
# Установите зависимости
pip install groq google-generativeai huggingface_hub

# Настройте .env
cp .env.example .env
# Добавьте API ключи в .env

# Проверьте статус
python -m src.llm.status_checker
```

### 2. Запуск бота

```bash
python vibe_coding_bot.py
```

### 3. Запуск dashboard (опционально)

```bash
python -m src.llm.dashboard
# Откройте http://localhost:8080/dashboard
```

### 4. CLI команды (в Telegram)

```
/llm_status - Проверка статуса провайдеров
/llm_stats - Статистика использования
/llm_switch groq - Переключение провайдера
/llm_cache_clear - Очистка кэша
/llm_reload - Перезагрузка конфигурации
```
